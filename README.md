## 🎮 Controls

### Player 1 - Keyboard
- Step Forward: **W**
- Step Backward: **S**
- Parry: **A**
- Attack: **F**
- Lunge Attack: **Shift + W**
- Backdash: **Shift + S**

### Player 1 - Controller
*(Compatible with PS4 and other standard game controllers)*  
- Step Forward: **Left Stick Forward**
- Step Backward: **Left Stick Backward**
- Parry: **L1**
- Attack: **Square**
- Lunge Attack: **Left Stick Forward + L3**
- Backdash: **Left Stick Back + L3**

### Player 2 - Keyboard
- Step Forward: **Arrow Up**
- Step Backward: **Arrow Down**
- Parry: **Arrow Left**
- Attack: **Enter**
- Lunge Attack: **Right Ctrl + Arrow Up** / **Right Alt + Arrow Up**
- Backdash: **Right Ctrl + Arrow Down** / **Right Alt + Arrow Down**
